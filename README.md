
# PrivateMesh

A decentralized peer to peer messaging platform.

## Project Description

PrivateMesh is a decentralized messaging application built to give users direct control over their communication. Instead of relying on centralized servers, the platform connects users directly and stores chat data on their own devices. Users can create groups, organize channels, and exchange messages in real time. The project focuses on privacy, reliability, and simple communication.
